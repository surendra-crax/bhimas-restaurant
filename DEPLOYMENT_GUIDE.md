# 🚀 Deployment Guide for Bhimas Kitchen on LWS hosting

This document provides a step-by-step guide to deploying the **Bhimas Traditional Indian Kitchen** website from your local MAMP environment to your live **LWS Panel** hosting.

---

## 📋 Pre-Deployment Configuration

We have modified `php/config.php` to automatically detect your environment. 
- When running on `localhost` (MAMP), it will continue using your local database settings (port `8889`, password `root`).
- When running on your live domain (`bhimas.lu`), it will automatically switch to production mode, disable error outputs, and look for your live database credentials.

### Step 1: Add your Live Database Credentials
Open your local `php/config.php` file and scroll down to the `else` block under `2. DATABASE CONSTANTS` (around line 70). Replace the placeholders with the database credentials you will create on LWS (instructions below):

```php
} else {
    // ── Live LWS Hosting Settings ──
    define('DB_HOST',    'localhost');             // Usually localhost
    define('DB_NAME',    'YOUR_LWS_DB_NAME');      // e.g., lws799138_bhimas
    define('DB_USER',    'YOUR_LWS_DB_USER');      // e.g., lws799138_user
    define('DB_PASS',    'YOUR_LWS_DB_PASSWORD');  // Your secure password
    define('DB_PORT',    3306);                    // Standard Live MySQL port
}
```

## 🛠️ Step-by-Step Deployment

### 1. Set Up the Live Database on LWS
1. Log in to your **LWS Panel** (as shown in your screenshot).
2. Go to the **Database & PHP** section and click on **MySQL & phpMyAdmin**.
3. Create a new database:
   - Name it (e.g., `bhimas_db` or use the default name generated by LWS).
4. Create a database user and assign a strong, secure password.
5. Grant the user **All Privileges** to the new database.
6. **Save these credentials!** You will need them for the `config.php` file.

### 2. Import the Database Schema
1. Inside the LWS **MySQL & phpMyAdmin** section, click the login button next to your database to open **phpMyAdmin**.
2. Select your newly created database from the left-hand menu.
3. Click the **Import** tab in the top navigation bar.
4. Click **Choose File** (or Browse) and select the [database.sql](file:///Applications/MAMP/htdocs/bhimas/database.sql) file from your local project directory.
5. Scroll to the bottom and click **Go** (or Import).
6. Verify that your database tables (`bookings`, `orders`, `order_items`, `settings`) have been created successfully.

### 3. Upload Project Files to LWS
You can upload your files using FTP (recommended for speed and reliability) or the LWS File Manager.

#### Option A: Using FTP (FileZilla) - *Recommended*
1. On the LWS Panel, go to the **Files** section and click **FTP account(s)** to find or create your FTP credentials (host, username, password).
2. Download and open [FileZilla](https://filezilla-project.org/).
3. Enter your FTP connection details:
   - **Host**: `ftp.bhimas.lu` (or the IP address listed in your LWS Panel)
   - **Username**: Your LWS FTP username
   - **Password**: Your FTP password
   - **Port**: `21` (default FTP port)
4. Click **Quickconnect**.
5. Once connected, look at the remote site panel (right side) and navigate to the web root directory (usually named `public_html` or `web`).
6. In the local site panel (left side), open `/Applications/MAMP/htdocs/bhimas/`.
7. Select **all files and folders** inside the `bhimas/` directory (including the new `.htaccess` file, `index.html`, `css/`, `js/`, `php/`, `admin/`, etc.).
8. Drag and drop them to the remote site panel on the right side to start the upload.

#### Option B: Using the LWS Web File Manager
1. On your local machine, select all files inside `/Applications/MAMP/htdocs/bhimas/` (except `.DS_Store` and the `.git` folder) and compress them into a `.zip` archive.
2. In your LWS Panel, go to **Files** -> **File manager**.
3. Navigate to your web root folder (`public_html` or `web`).
4. Click the **Upload** button, select your zip archive, and wait for it to upload.
5. Right-click the uploaded zip archive in the File Manager and choose **Extract** (or Unzip).
6. Move the files if they extracted into a subdirectory; they should sit directly in the root of the domain.

## 🔒 Post-Deployment Security & Optimization

### 1. Activate SSL (HTTPS) - *Critical*
1. In your LWS Panel, go to the **Security** section and click **SSL**.
2. Select your domain (`bhimas.lu`).
3. Click to install the free **Let's Encrypt SSL certificate**.
4. It will take 5 to 15 minutes to generate and activate.
5. Once active, the `.htaccess` file we added will automatically force all visitors to browse your site via secure `https://bhimas.lu`.

### 2. Verify Folder Permissions
1. In FileZilla, right-click the `images/` directory in the remote panel and click **File permissions...**
2. Ensure the numeric value is set to `755` (default) or `775`. This is necessary so the admin panel can upload hero images.

### 3. Change Admin Password
By default, the admin panel password is set to `bhimas_admin_2025` in `php/config.php`.
For safety on a live public website:
- Open `php/config.php` and change the default value on line 84:
  ```php
  define('ADMIN_PASSWORD',   getenv('ADMIN_PASSWORD') ?: 'YOUR_NEW_SECURE_PASSWORD');
  ```
- Or, define the environment variable `ADMIN_PASSWORD` on your server using LWS configurations.

### 4. Test Form Submissions
Visit your website in a web browser (e.g., `https://bhimas.lu`) and test:
1. **Reservation form** (confirm you get the success notification).
2. **Takeaway checkout** (confirm the cart processes).
3. **Admin login** (visit `https://bhimas.lu/admin/` and log in with your credentials).

## 📁 Live File Hierarchy Reference
On your live LWS hosting space, your files should be placed inside the web root folder like this:

```
public_html/ (or web/)
├── .htaccess               <-- (Forces HTTPS, blocks sensitive files, speeds up loading)
├── index.html              <-- Main homepage
├── menu.html               <-- Menu page
├── reservation.html        <-- Booking page
├── takeaway.html           <-- Takeaway page
├── contact.html            <-- Contact page
├── css/                    <-- Stylesheets folder
├── js/                     <-- Javascript folder
├── images/                 <-- Image uploads folder (Must be writable / 755)
├── php/
│   ├── config.php          <-- Holds your live database credentials
│   └── (submit scripts...)
└── admin/                  <-- Admin panel dashboard scripts
```
